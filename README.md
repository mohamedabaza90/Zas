# ZAS OneBrain

منظومة تشغيل وذكاء مؤسسي لشركة ZAS Innovation للتصميم والتشطيبات.
**الفكرة في جملة:** أدخل المعلومة مرة واحدة ← كل قسم يستفيد منها ← الإدارة تشوف الربح والتأخير والمشاكل والتحصيل من لوحة واحدة.

خطة البناء كاملة، قسم بقسم: [docs/ROADMAP.md](docs/ROADMAP.md)

## إزاي تشغله على جهازك (Windows)

1. نزّل **Python** من https://www.python.org/downloads/ ، وأثناء التثبيت علّم على **Add Python to PATH**.
2. نزّل المشروع من GitHub: زرار **Code** ← **Download ZIP**، وبعدين فك الضغط.
3. دبل كليك على ملف **`run.bat`**.
4. أول مرة بياخد حوالي دقيقة يجهز نفسه، وبعدين المتصفح بيفتح لوحده على `http://127.0.0.1:8000`.

عشان تقفل البرنامج، اقفل الشاشة السودا.
البيانات بتتحفظ في فولدر `data` جوه المشروع.

## اللي اتعمل لحد دلوقتي — القسم 1: الأساس

- **رقم موحد** لكل مشروع (`ZAS-2026-001`) ولكل عميل (`CL-0001`) ولكل موظف (`EMP-001`). كل الأقسام هتشتغل على نفس الرقم.
- **رحلة المشروع بمراحلها العشرة:** جذب ← بيع ومعاينة ← تصميم ← تسعير ← تعاقد ← تخطيط ← تنفيذ ← متابعة ← تسليم ← خدمة.
- **نوع التعاقد:** نسبة إشراف (Cost-plus) أو أتعاب ثابتة.
- **سجل تغييرات:** كل إضافة أو تعديل بيتسجل بمين عمله وإمتى.
- **بيانات كل شركة منفصلة:** ده بيجهز النظام إنه يتباع بعد كده كاشتراك (SaaS) لشركات تانية.
- **بيانات تجريبية** عليها علامة «تجريبي»، عشان الشاشات ما تبقاش فاضية. دي مش بيانات حقيقية.

## للمطورين

```bash
pip install -r requirements-dev.txt
python -m pytest -q
python -m uvicorn onebrain.main:create_app --factory --reload
```

التقنيات: Python و FastAPI و SQLModel (SQLite دلوقتي، وPostgreSQL بعدين)، والشاشات Jinja2 بالعربي (RTL).
